## Long description (≤300 characters)

LRP OS turns an x86_64 PC into a TV appliance. A Debian 13 ISO boots into a kiosk panel; an Android APK or iOS PWA pairs by 6-digit PIN and controls input, apps, audio, Wi-Fi, Bluetooth and power over the LAN. No cloud, accounts, license keys, telemetry or OTA. GPL-3.0.
